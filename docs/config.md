# nomonad config reference

Generated by `make docs` from `nomonad --describe` (schema version 1). Do not edit by hand.

The config is `$XDG_CONFIG_HOME/nomonad/config.scm`, a sequence of the top-level forms below. Upper case words in patterns are placeholders, `[...]` marks an optional keyword and `...` means more entries of the same shape.

## Top-level forms

### defkeys

Key bindings, one (MODS KEY ACTION) per entry. Binding the same chord twice is an error.

```
(defkeys
  (MODS KEY ACTION)
  ...)
```

| Placeholder | Type |
|---|---|
| `MODS` | `mods` |
| `KEY` | `keysym` |
| `ACTION` | `action` |

### defmouse

Pointer button bindings, one (MODS BUTTON ACTION) per entry. Binding the same chord twice is an error.

```
(defmouse
  (MODS BUTTON ACTION)
  ...)
```

| Placeholder | Type |
|---|---|
| `MODS` | `mods` |
| `BUTTON` | `(one-of left right middle)` |
| `ACTION` | `action` |

### defsubmap

A keymap entered with (submap NAME). Its keys are pressed without modifiers, any other key leaves it. Redefining a name is an error.

```
(defsubmap NAME
  (KEY ACTION)
  ...)
```

| Placeholder | Type |
|---|---|
| `NAME` | `text` |
| `KEY` | `keysym` |
| `ACTION` | `action` |

### defrules

Window rules. float makes matching windows float. ignore leaves them unmanaged: not tiled, no border, never focused. A keyword given twice keeps the last value.

```
(defrules
  (float MATCHER [:center bool] [:glob bool])
  (ignore MATCHER [:glob bool])
  ...)
```

| Placeholder | Type |
|---|---|
| `MATCHER` | `matcher` |

Keywords of `(float MATCHER)`:

| Keyword | Type | Default | Description |
|---|---|---|---|
| `:center` | `bool` | `false` | Center the window on its output when it starts floating. |
| `:glob` | `bool` | `false` | Match the pattern as an fnmatch(3) glob instead of exactly. |

Keywords of `(ignore MATCHER)`:

| Keyword | Type | Default | Description |
|---|---|---|---|
| `:glob` | `bool` | `false` | Match the pattern as an fnmatch(3) glob instead of exactly. |

### defscratchpads

Scratchpads for (scratchpad NAME): the command that starts the window and the matcher that recognizes it. Redefining a name is an error. A keyword given twice keeps the last value.

```
(defscratchpads
  (NAME (spawn COMMAND) MATCHER [:geometry (list-of fraction 4 4)] [:glob bool])
  ...)
```

| Placeholder | Type |
|---|---|
| `NAME` | `text` |
| `COMMAND` | `string` |
| `MATCHER` | `(patterns (app-id PATTERN) (title PATTERN))` |
| `PATTERN` | `string` |

Keywords of `(NAME (spawn COMMAND) MATCHER)`:

| Keyword | Type | Default | Description |
|---|---|---|---|
| `:geometry` | `(list-of fraction 4 4)` |  | (X Y W H) as fractions of the whole output, bars included. W and H above 0, X + W and Y + H at most 1. Unset, the window is centered. |
| `:glob` | `bool` | `false` | Match the pattern as an fnmatch(3) glob instead of exactly. |

### defcfg

Settings, one block per entry, see the defcfg entries. Blocks apply in order, a later block wins for what it sets, and a keyword given twice keeps the last value.

```
(defcfg
  BLOCK
  ...)
```

| Placeholder | Type |
|---|---|
| `BLOCK` | `(ref defcfg)` |

### defalias

Every @NAME atom elsewhere in the config is replaced by BODY before parsing. Bodies do not expand other aliases. Redefining a name is an error.

```
(defalias NAME BODY)
```

| Placeholder | Type |
|---|---|
| `NAME` | `atom` |
| `BODY` | `any` |

## defcfg blocks

### borders

Window borders. Colors are "#RRGGBB" or "#RRGGBBAA".

```
(defcfg (borders [:width VALUE] [:focused VALUE] [:unfocused VALUE] [:captured VALUE] [:smart VALUE]))
```

| Keyword | Type | Default | Description |
|---|---|---|---|
| `:width` | `(integer 0 1000)` | `3` | Border width in pixels, 0 turns borders off. |
| `:focused` | `color` | `"#21fc0dff"` | Border color of the focused window. |
| `:unfocused` | `color` | `"#4c566aff"` | Border color of the other windows. |
| `:captured` | `color` |  | Border color of a window that is being screen captured, or that sits on a captured output. Unset, captured windows keep their normal color. |
| `:smart` | `bool` | `false` | No border when the workspace has a single tile. |

### gaps

Outer gaps at the output edges and inner gaps around tiles.

```
(defcfg (gaps [:top VALUE] [:bottom VALUE] [:left VALUE] [:right VALUE] [:inner VALUE] [:smart VALUE]))
```

| Keyword | Type | Default | Description |
|---|---|---|---|
| `:top` | `(integer 0 1000)` | `0` | Pixels kept free at the top of each output. |
| `:bottom` | `(integer 0 1000)` | `0` | Pixels kept free at the bottom of each output. |
| `:left` | `(integer 0 1000)` | `0` | Pixels kept free at the left of each output. |
| `:right` | `(integer 0 1000)` | `0` | Pixels kept free at the right of each output. |
| `:inner` | `(integer 0 1000)` | `0` | Padding in pixels around each tile. |
| `:smart` | `bool` | `false` | No outer or inner gaps when the workspace has a single tile. |

### layout

A single layout for every workspace, same as (layouts NAME).

```
(defcfg (layout NAME))
```

| Argument | Type | Default |
|---|---|---|
| `NAME` | `(one-of tall bsp deck mirror-tall three-columns grid tabbed spiral two-pane resizable-tall)` | `tall` |

### layouts

The layout cycle of every workspace, in order. The first is used at start, next-layout and prev-layout walk the rest.

```
(defcfg (layouts NAMES ...))
```

| Argument | Type | Default |
|---|---|---|
| `NAMES` | `(rest-of (one-of tall bsp deck mirror-tall three-columns grid tabbed spiral two-pane resizable-tall) 1 16)` | `(tall)` |

### decorations

ssd asks clients to drop their titlebars, csd lets them draw their own. Clients that only support csd keep theirs.

```
(defcfg (decorations MODE))
```

| Argument | Type | Default |
|---|---|---|
| `MODE` | `(one-of ssd csd)` | `ssd` |

### repeat

Keyboard repeat. Without this block river's defaults apply.

```
(defcfg (repeat [:rate VALUE] [:delay VALUE]))
```

| Keyword | Type | Default | Description |
|---|---|---|---|
| `:rate` | `(integer 0 1000)` | `25` | Key repeats per second, 0 turns repeat off. |
| `:delay` | `(integer 0 10000)` | `600` | Milliseconds a key is held before it repeats. |

### cursor

Cursor theme and size.

```
(defcfg (cursor :theme VALUE [:size VALUE]))
```

| Keyword | Type | Default | Description |
|---|---|---|---|
| `:theme` | `text` | required | Xcursor theme name, also exported as XCURSOR_THEME. |
| `:size` | `(integer 1 512)` | `24` | Cursor size in pixels, also exported as XCURSOR_SIZE. |

### touchpad

Touchpad settings for every touchpad. A key that is not given keeps the device default.

```
(defcfg (touchpad [:tap VALUE] [:natural-scroll VALUE] [:dwt VALUE] [:middle-emulation VALUE]))
```

| Keyword | Type | Default | Description |
|---|---|---|---|
| `:tap` | `bool` |  | Tap to click. |
| `:natural-scroll` | `bool` |  | Content follows the fingers when scrolling. |
| `:dwt` | `bool` |  | Disable the touchpad while typing. |
| `:middle-emulation` | `bool` |  | Pressing left and right together is a middle click. |

### keymap

XKB keymap for every keyboard. Keys not given use the xkbcommon defaults. The keymap must compile.

```
(defcfg (keymap [:rules VALUE] [:model VALUE] [:layout VALUE] [:variant VALUE] [:options VALUE]))
```

| Keyword | Type | Default | Description |
|---|---|---|---|
| `:rules` | `text` |  | XKB rules, usually evdev. |
| `:model` | `text` |  | XKB model, e.g. pc105. |
| `:layout` | `text` |  | XKB layouts, comma separated, e.g. "us,dk". |
| `:variant` | `text` |  | XKB variants, one per layout, comma separated. |
| `:options` | `text` |  | XKB options, e.g. "ctrl:nocaps,grp:alt_shift_toggle". |

## Actions

Used as the ACTION of defkeys, defmouse and defsubmap entries, and by `nomonad -m`.

| Action | Arguments | Layout | Description |
|---|---|---|---|
| `(spawn COMMAND)` | `COMMAND` `string` |  | Run COMMAND with /bin/sh -c, in its own systemd scope when the user manager is reachable and NM_SPAWN_SCOPE is not 0. |
| `close` |  |  | Ask the focused window to close. |
| `focus-next` |  |  | Focus the next window on the workspace, wrapping around. |
| `focus-prev` |  |  | Focus the previous window on the workspace, wrapping around. |
| `focus-master` |  |  | Focus the first window on the workspace. |
| `focus-last` |  |  | Focus the previously focused window. Repeating toggles between the two. |
| `focus-mru-next` |  |  | Alt-tab: step to the next window in most recently used order. The cycle ends when the binding's modifiers other than Shift are released, or on any other focus change. |
| `focus-mru-prev` |  |  | Alt-tab backwards: step to the previous window in most recently used order. |
| `swap-next` |  |  | Swap the focused window with the next one in the workspace order. |
| `swap-prev` |  |  | Swap the focused window with the previous one in the workspace order. |
| `shrink-master` |  |  | Shrink the master area by 3 percent. Tall, mirror-tall, three-columns, two-pane and resizable-tall. |
| `expand-master` |  |  | Grow the master area by 3 percent. Same layouts as shrink-master. |
| `inc-master` |  |  | One more window in the master area. Same layouts as shrink-master. |
| `dec-master` |  |  | One less window in the master area, not below 0. |
| `toggle-float` |  |  | Float the focused tile at its current geometry, or sink a float back into the tiling. |
| `toggle-fullscreen` |  |  | Make the focused window cover the usable area of its output, bars stay visible. The client is not told it is fullscreen. |
| `toggle-sticky` |  |  | Make the focused window sticky: it floats and follows its output across workspace switches. Again to unstick. |
| `toggle-scratchpad` |  |  | Stash the focused window as the dynamic scratchpad, or bring the stashed one back as a focused float. |
| `(scratchpad NAME)` | `NAME` `(name defscratchpads)` |  | Show or hide the named scratchpad, spawning it when it is not running. |
| `(submap NAME)` | `NAME` `(name defsubmap)` |  | Enter the named submap. The next key runs one of its bindings, any other key leaves the submap. |
| `(workspace WORKSPACE)` | `WORKSPACE` `(integer 1 9)` |  | Show workspace N on the focused output. |
| `(move-to-workspace WORKSPACE)` | `WORKSPACE` `(integer 1 9)` |  | Send the focused window to workspace N. |
| `(move-to-workspace-follow WORKSPACE)` | `WORKSPACE` `(integer 1 9)` |  | Send the focused window to workspace N and show it there. |
| `next-workspace` |  |  | Show the next workspace on the focused output, wrapping around. |
| `prev-workspace` |  |  | Show the previous workspace on the focused output, wrapping around. |
| `(focus-output OUTPUT)` | `OUTPUT` `(integer 0 64)` |  | Focus output N, counting from 0. |
| `(move-to-output OUTPUT)` | `OUTPUT` `(integer 0 64)` |  | Send the focused window to the workspace shown on output N. |
| `next-layout` |  |  | Switch the workspace to the next layout of the defcfg layouts cycle. |
| `prev-layout` |  |  | Switch the workspace to the previous layout of the defcfg layouts cycle. |
| `move-window` |  |  | Drag the window under the pointer. Meant for defmouse. |
| `resize-window` |  |  | Resize the window under the pointer by its bottom right corner. Meant for defmouse. |
| `(resize EDGE DELTA)` | `EDGE` `(one-of left right up down)`, `DELTA` `(integer -10000 10000)` |  | Move EDGE of the focused float by DELTA pixels, positive grows the window. Floats only. |
| `bsp-rotate` |  | bsp | Flip the split holding the focused window between side by side and stacked. |
| `bsp-swap` |  | bsp | Swap the two halves of the split holding the focused window. |
| `bsp-expand-l` |  | bsp | Grow the focused window by moving its left edge left. |
| `bsp-expand-r` |  | bsp | Grow the focused window by moving its right edge right. |
| `bsp-expand-u` |  | bsp | Grow the focused window by moving its top edge up. |
| `bsp-expand-d` |  | bsp | Grow the focused window by moving its bottom edge down. |
| `bsp-shrink-l` |  | bsp | Shrink the focused window by moving its left edge right. |
| `bsp-shrink-r` |  | bsp | Shrink the focused window by moving its right edge left. |
| `bsp-shrink-u` |  | bsp | Shrink the focused window by moving its top edge down. |
| `bsp-shrink-d` |  | bsp | Shrink the focused window by moving its bottom edge up. |
| `bsp-balance` |  | bsp | Set every split of the tree to 50/50. Same as bsp-equalize. |
| `bsp-equalize` |  | bsp | Set every split of the tree to 50/50. |
| `bsp-balance-area` |  | bsp | Set the splits so every window gets the same area. |
| `bsp-rotate-cw` |  | bsp | Rotate the whole tree 90 degrees clockwise. |
| `bsp-rotate-ccw` |  | bsp | Rotate the whole tree 90 degrees counterclockwise. |
| `rt-expand-cell` |  | resizable-tall | Make the focused window 20 px taller, taken from its column neighbour. |
| `rt-shrink-cell` |  | resizable-tall | Make the focused window 20 px shorter, given to its column neighbour. |
| `reload-config` |  |  | Reload the config file. Edits are also picked up on their own. |
| `restart` |  |  | Re-exec nomonad, keeping windows, workspaces, layouts and focus. |
| `exit` |  |  | End the river session. |

## Types

| Type | Definition | Description |
|---|---|---|
| `string` |  | A double quoted string. |
| `atom` |  | A bare word. |
| `text` |  | A string or a bare word. |
| `any` |  | Any s-expression. |
| `bool` |  | true or false. |
| `color` |  | "#RRGGBB" or "#RRGGBBAA". |
| `fraction` |  | A decimal from 0 to 1, e.g. 0.25. |
| `mods` |  | Modifiers in one atom, M Super, A Alt, C Control, S Shift, optionally joined by -, e.g. M-S. () for none. |
| `keysym` |  | An xkbcommon key name, case sensitive, e.g. Return, a, F1, XF86AudioMute. |
| `action` |  | One of the action entries: NAME, or (NAME ARG ...) for an action with :args. |
| `matcher` | `(patterns (app-id PATTERN) (title PATTERN) (parent) (kind dialog)), PATTERN is string` | app-id and title compare the window's app id or title with PATTERN. (parent) and (kind dialog) both match windows that have a parent, such as dialogs. |
